# 伊娃桌面宠物 · Mac 2.0.1

Mac 2.0.1 集中统一伊娃在 macOS 与 GitHub 上的图标和标准形象。

## 更新内容

- 应用图标改为简约伊娃头部，移除原先大面积蓝色背景
- 新图标以白色外壳、黑色面屏和少量蓝色眼睛为主
- 重新生成 16–1024 像素完整 macOS `.icns` 资源
- 菜单栏使用独立的单色伊娃头部模板，自动适配系统外观
- GitHub 标准形象移除旧版胸前三点，更新为居中的单个圆形玻璃核心
- 保留 Mac 2.0 的火箭玩耍、方向拖动、随机互动和四向性能卡片功能

## 安装

1. 下载 `Eva-Desktop-Pet-Mac-2.0.1.zip`。
2. 解压后，将“Eva Desktop Pet.app”拖入“应用程序”文件夹。
3. 首次打开如遇 macOS 安全提示，请在 Finder 中右键应用并选择“打开”。

## 系统要求

- macOS 13 或更高版本
- Apple Silicon（当前发布包为 arm64）

所有偏好、提醒和性能采样结果均保存在本机。
