# 伊娃桌面宠物 · Mac 2.0

Mac 2.0 是伊娃桌面宠物的一次完整互动体验升级：角色动作更连贯，拖动更跟手，玩耍、休眠、性能卡片和菜单栏入口也已统一到同一套温暖玻璃风格。

## 亮点

- 玩耍时变为白、黑、蓝三色小火箭，沿连续“8”字路线飞行
- 小火箭状态支持直接拖动，朝向、尾焰和阴影实时跟随轨迹
- 点击会从其余状态中随机选择新动作，增加陪伴感和可玩性
- 五种动作使用匹配的眼睛表情、姿态、胸前柔光和自然过渡
- 性能卡片支持上、下、左、右固定位置与完全透明背景
- 休眠状态增加醒目的玻璃月亮和 `Zzz` 提示
- 菜单栏改为简约伊娃头像，自动适配浅色、深色和选中状态
- 保留自适应刷新、资源缓存与关闭监控即停止采样的轻量设计

## 安装

1. 下载 `Eva-Desktop-Pet-Mac-2.0.0.zip`。
2. 解压后，将“Eva Desktop Pet.app”拖入“应用程序”文件夹。
3. 首次打开如遇 macOS 安全提示，请在 Finder 中右键应用并选择“打开”。

## 系统要求

- macOS 13 或更高版本
- Apple Silicon（当前发布包为 arm64）

## 数据说明

CPU 占用率来自公开的 Mach 主机接口。GPU 数据取决于当前 Mac 是否通过 IORegistry 提供相应统计。macOS 不向普通第三方应用提供统一的 CPU/GPU 摄氏温度接口，因此应用会明确显示系统热状态或“系统限制”，不会伪造温度。
